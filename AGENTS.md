# slopsubs

## Agent skills

### Issue tracker

Issues live in NavHur/slopsubs GitHub Issues, through `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default role names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.

### Data refresh

Refreshing `src/data`, or an import script failing on a source's layout: follow `docs/agents/data-refresh.md`.
